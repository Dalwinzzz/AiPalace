### 架构

整体架构

```mermaid
graph TD
    A["My Brain"] --> B["⚙️ 数据中心（隐藏）"]
    A --> C["📘 学习"]
    A --> D["💼 工作"]
    A --> E["🍀 生活"]

    B --> F["全局知识引擎<br/>唯一源数据库"]
    B --> G["模板工坊<br/>数据库模板 + 同步模块库"]

    C --> H["学习视图<br/>过滤：领域=学习"]
    D --> I["工作视图<br/>过滤：领域=工作"]
    E --> J["生活视图<br/>过滤：领域=生活"]

    H -.同一数据源.-> F
    I -.同一数据源.-> F
    J -.同一数据源.-> F

```
