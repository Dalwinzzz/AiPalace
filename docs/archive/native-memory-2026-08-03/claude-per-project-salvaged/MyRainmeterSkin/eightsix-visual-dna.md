**真正的 86 视觉 DNA（来自官方原图，不是二手转述）：**
- 核心界面是「军用电子花名册/数据表格」：编号列(001-024) + PERS(人名) + POWER/SPEED/ALT/TEMP/PARA 列，行行严格对齐。这是最标志性的界面，不是炫酷曲线。
- 配色**亮蓝白底**：淡蓝白底 + 钢蓝线条 + 深蓝近黑文字，唯一强调色是猩红(DESTROYED 血红)。冷蓝统治画面 + 猩红只在死亡/警告刺出，不是红蓝平分。
- 字体：等宽数字感 + 全大写英文 + 军用制式编号(S-1, A-1, B-leader)。军用 HUD 共识字体 Oxanium/等宽。
- signature moment：猩红「DESTROYED」斜压在行上的阵亡标记。
- 细节：蓝色坐标网格背景、月相符号、↑↓升降箭头+数值。
- 气质：清醒、冷酷、官僚式精密 —— 共和国把 86 区的人当数据管理。

**关键纠偏**：旧版（深色 + 红蓝框 + 汉字装饰 + 中文乱码）方向完全错了，所以「非常不理想」。真 86 是亮蓝白底军用数据台，不是赛博朋克黑红。

**Rainmeter 社区调研结论（用户要求从 zhutix/贴吧/pixiv 实地搜集，chrome 插件）：**
- 致美化 TETRACTYS 套件：组件全部做成独立圆角卡片 + 深色半透明底，模块化堆叠，底部一排 Dock 程序图标。
- 贴吧「透明度」皮肤：中央居中布局，时间/日期/频谱/歌词全部纯透明无底板直接叠壁纸，当前歌词行橙红高亮。
- pixiv 86 插画配色锚点：冷蓝/钢蓝 + 银白(雷娜白发/制服) + 军装深色统治画面，暖色只在徽章金/红点缀；作品标志是猩红「86」大数字。
- **用户对 v3 的 4 条批注**：①组件底不要实色背景，改透明可调毛玻璃 ②时钟字体纯白，不要红白蓝多色 ③Dock 不要做成文件夹方块，改 86 动画机架上的机体 logo(Reginleif/Juggernaut 战队机徽) ④花名册 CRITICAL 斜压标记保留。

**v4 仍被批「没跳脱束缚」→ v5 方向(用户拍板)：**
- 布局骨架换掉「四角对称堆面板」(v1-v4 一直犯的 AI 默认布局)。改 **左侧竖直指挥控制栏**(花名册/音乐/日历堆叠在左侧一条) + **屏幕主体大留白** + 中央时钟主视觉 + 底部 dock。打破对称、信息归一侧、强呼吸感。
- Dock 图标 = **每个 Spearhead 成员的个人纹章 logo**(不是抽象机甲剪影)。参考 Undertaker=无头骑士骷髅(Dullahan)+剑+斗篷的黑白手绘线稿徽记风。我用 SVG 同风格重绘 5 个：UNDERTAKER/BLACK DOG/GUN SNAKE/LAUGHING FOX/SNOW WITCH，线稿徽记风,可上色钢蓝/猩红。
