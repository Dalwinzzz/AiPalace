- 日期：2026-07-03
- 状态：已定稿（用户逐节确认）
- 承继：ADR-0013（记忆层，M4 为其登记的待决项）、ADR-0014（always-on 瘦身，本 spec 定义豁免边界）、evolution.md §6.2（原始收敛路径）

## 1. 背景与目标

`~/.claude/CLAUDE.md` 与 `~/.codex/AGENTS.md` 平行维护全量全局指令：共享内容双侧重复（三条个人偏好 / Context7 / ConfigFile 策略 / superpowers ask-first），改一处易忘另一处；文件在仓外，不可版本化、双机不可同步。M4 目标：

- G1：工具无关共享规则收敛为单一源 `vault/memory/00-RULES/operating-rules.md`，SessionStart hook 双工具 always-on 注入。
- G2：native 全局文件瘦成**工具专属 stub**（不空），stub 本身入仓（`context/native/`），native 路径改软链派生——全局配置版本化、双机同步（P1/P2，同 commands 模式）。
- G3：消除双侧内容漂移；净 always-on token ≈ 持平或下降（去重）。

非目标（N）：

- N1：不动 `context/rules/`（path-scoped 机制 B）与 native memory 并发机制（机制 C）；`~/.claude/projects/…/memory/` 存量按既有策略渐进迁移，不在 M4 一次清。
- N2：不改 AiPalace 仓库级 `CLAUDE.md`（repo 指令，在仓内，另一回事）。
- N3：不引入新注入机制——只扩既有机制 A 的 files 元组。

## 2. 锁定决策

| # | 决策 | 依据 |
|---|------|------|
| D1 | 架构 = **A+C**：共享规则 hook 注入 + native stub 入仓软链派生 | 用户拍板；P1 彻底收敛，软链模式已被 commands/skills 实证 |
| D2 | **dbq 只读查库规则进共享层**（Codex 同获）：只读铁律/禁读连接配置约束随规则一起生效 | 用户拍板；内容工具无关，Codex 侧 pretooluse guard 防线已存在 |
| D3 | Cross-Tool Skill Source / Harness Governance 进共享层；Workflow Memory Boundary 留 Codex stub | 前两者是工具无关指针；后者是 AGENTS.md 自身定位声明 |
| D4 | 注入顺序：`files=("00-RULES/operating-rules.md", "INDEX.md")`——法律在前、导航在后 | 规则优先级高于导航 |
| D5 | operating-rules.md 是 **ADR-0014 后第二个获准 always-on 项**；豁免理由：内容原本就经 native 文件 always-on，M4 只换源+去重，净 token ≈ 0 或下降 | ADR-0016 记录豁免边界；00-RULES 其余文件仍按需 |
| D6 | stub 不空：受管头注 + 工具专属规则 + 兜底指针（hook 失效时手读 vault 绝对路径） | 用户早期要求"瘦成指针 stub 而非清空"；兜底保证 hook 单点失效不致裸奔 |
| D7 | 执行前双备份：原件快照入仓 `docs/archive/native-globals-2026-07-03/`（P8 留痕）+ 本地 `.bak-m4` 副本；回滚 = 删软链恢复原件 | 仓外全局配置，特性分支不保护，须独立回滚路径 |

## 4. 注入机制变更（机制 A 扩展）

- `tools/hooks/sessionstart.py`：注入调用改 `files=("00-RULES/operating-rules.md", "INDEX.md")`（D4）。`inject_index` 已支持元组，无签名变更。
- 注入块首行带来源标识（如 `[操作规则]` / 现有 INDEX 块），便于 stub 兜底指针判断"是否已注入"。
- 测试：`tools/hooks/test_sessionstart.py` + `tests/test_inject_index.py` 扩断言（双文件顺序、缺文件容错），保持全绿。
- token 影响：共享内容从两份 native 全文 → 一份 hook 注入，净 always-on 持平或下降（D5）。

## 5. 执行安全（P6）

```
备份(D7) → 写三个新文件(入仓) → 改 hook files 元组 + 测试 → 建软链(rm 原件 → ln -s) → 实测门(D8) → 文档收口
```

- 软链操作是**仓外副作用**，特性分支不保护——放在实测门通过路径上按序执行，单独 commit 记录操作说明。
- 回滚：`rm ~/.claude/CLAUDE.md ~/.codex/AGENTS.md && cp <.bak-m4 副本> 回原位`；hook files 元组还原一行。

## 8. 风险

| 风险 | 对策 |
|------|------|
| 软链后某工具版本更新改变文件读取行为 | stub 兜底指针（D6）+ 备份留存；doctor 类巡检可后续扩展 |
